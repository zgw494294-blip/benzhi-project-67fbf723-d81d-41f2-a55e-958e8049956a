# 种子萌发试验审定工作台

这是面向种质研究团队的单流程浏览器应用，用于建立萌发试验、预检并锁定处理方案、逐日批量记录全部重复组观察、追溯指标证据、登记和证据销项偏差，以及生成和审定只读审定包。数据保存在本地 `.data` 目录的 JSON 快照、链式摘要事件记录和只读历次审定包中，服务提供同源 HTML 页面和 JSON API。

试验列表可组合筛选物种、采集批号和状态。所有业务写请求均通过原有 `/api/trials/{id}/{action}` 路径执行，要求携带当前 `expectedRevision` 和 `Idempotency-Key`；方案必须先通过 `protocol-preview` 获得 `contentDigest` 再锁定。观察录入以单个试验日的 `observations` 数组原子提交。送审时立即固化方案、观察、指标与偏差快照，退回使用结构化问题清单，关闭后的批次统一只读。详情页可筛选状态事件并显示摘要链诊断。

标准构建、运行和测试：

```text
go test ./...
go run ./cmd/server -addr=127.0.0.1:19081
```

浏览器访问 `http://127.0.0.1:19081/`。监听地址也可通过 `-addr=127.0.0.1:<port>` 指定，或设置 `PORT` 端口号；默认仅绑定 `127.0.0.1:19081`。执行完整回环自检：

```text
go run ./cmd/server -selfcheck -addr=127.0.0.1:19081
```
